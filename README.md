# KANDITER — сайт рецептов (React + Vite + Firebase)

> Ключи Firebase (проект konditer-d8188) уже вшиты в проект и лежат в `.env`.
> Остаётся только включить Firestore и вставить правила (шаг 1).

## 1. Firebase
1. https://console.firebase.google.com → Создать проект.
2. Build → **Firestore Database** → Create database (регион любой).
3. Вкладка **Rules** → вставьте содержимое файла `firestore.rules` → Publish.
4. Project settings → Your apps → **Web (</>)** → скопируйте конфиг.

## 2. Запуск на компьютере
```bash
npm install
cp .env.example .env     # впишите ключи Firebase
npm run dev
```

## 3. Публикация на Vercel
1. Загрузите проект на GitHub.
2. Vercel → Add New Project → выберите репозиторий (Framework: Vite определится сам).
3. Переменные окружения добавлять не обязательно — ключи уже в коде. Нажмите Deploy.

## Картинки с Google Диска
Файл → Поделиться → «Все, у кого есть ссылка» → скопировать ссылку и вставить в форму.
Сайт сам превратит её в прямую ссылку на картинку.

## Что где хранится
- Firebase (Firestore): группы, рецепты, фильтры, название, ссылка на логотип, цвета, валюта.
- Тема (светлая/тёмная): в браузере устройства.
- Фото: на Google Диске (в базе только ссылки).

## Безопасность
Правила в `firestore.rules` открывают запись всем — удобно для личного сайта, но любой, у кого есть адрес,
сможет менять данные. Если нужна защита — добавьте Firebase Authentication и ограничьте правила.

## Что нового
- Язык приложения: русский / румынский (меню → «Язык»). Выбор запоминается в браузере.
- Кнопка «Фильтры» рядом с поиском: окно со всеми фильтрами, можно выбрать несколько.
- В рецепте можно добавить несколько фото; в карточке показывается первое, в окне рецепта — галерея.
  Старые рецепты с одним фото продолжают работать.

Названия групп, фильтров и тексты рецептов не переводятся — они такие, как вы их написали.
